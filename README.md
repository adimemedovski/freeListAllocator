
# Free-List Allocator

A custom memory allocator exploring the management and reuse of dynamically allocated memory.

## Overview

Free-list allocation tracks available regions of memory so that previously released space can be reused for future allocations.

Unlike linear and stack allocators, free-list allocation is designed to accommodate less predictable allocation patterns.

## Concepts

- Dynamic memory management
- Free-list data structures
- Memory fragmentation
- Allocation and deallocation strategies

## Purpose

Built to develop a deeper understanding of memory management, data structures, and the trade-offs involved in allocator design.
